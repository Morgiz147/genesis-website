# GENESĪS — статическая вёрстка

Репозиторий содержит только клиентскую часть сайта: HTML-страницы, стили, JavaScript и медиафайлы. Серверные конфигурации, данные инфраструктуры и инструкции по развёртыванию намеренно не публикуются.

## Структура

| Путь | Содержимое |
| --- | --- |
| `index.html` | Главная страница лендинга. |
| `offer/index.html` | Страница договора-оферты по адресу `/offer/`. |
| `privacy-policy/index.html` | Страница политики конфиденциальности по адресу `/privacy-policy/`. |
| `offer.html`, `privacy-policy.html` | Резервные версии юридических страниц. |
| `css/` | Стили сайта: базовые правила, компоненты, секции и адаптивные брейкпоинты. |
| `js/` | Клиентские скрипты: общие сценарии, слайдеры и FAQ. |
| `assets/fonts/` | Локально подключаемые шрифты и сведения об их лицензии. |
| `assets/icons/` | SVG-иконки и логотип. |
| `assets/images/` | Растровая графика главного лендинга. |
| `assets/media/` | Оптимизированные изображения и мокапы для секций сайта. |

## Локальный просмотр

Откройте `index.html` в браузере или раздайте эту папку любым статическим веб-сервером. Для корректной работы внутренних ссылок используйте корень проекта как корень сайта.

## Публикация

При обновлении загружайте только файлы статической вёрстки и этот README. Конфигурации серверов, ключи, переменные окружения и прочие служебные данные в этот репозиторий не добавляются.
